# Sprint 3.2: Analíticas de Rendimiento Académico y Dashboard Predictivo — Plan de Implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implementar el motor de diagnóstico y analíticas académicas predictivas con gráficos nativos en Canvas Jetpack Compose e integrarlo en la pestaña `Calificaciones` mediante un conmutador segmentado táctil.

**Architecture:** Clean Architecture + MVI. Capa de dominio pura con `CalculateAcademicStatsUseCase` que procesa evaluaciones, materias, horarios, escalas de calificación y nota mínima aprobatoria; capa de presentación con componentes táctiles en Canvas puro (`AcademicProgressChart`, `GradeDistributionHistogram`) y tarjetas Bento (`AcademicEarlyWarningCard`, `AcademicWorkloadCard`) orquestadas en `AcademicAnalyticsContent`.

**Tech Stack:** Kotlin 2.0.21, Jetpack Compose Material 3, Android Canvas (`drawRect`, `drawRoundRect`, `drawPath`, `drawText`), Hilt 2.59, Coroutines Flow, JUnit 4, MockK.

**Spec:** [`docs/superpowers/specs/2026-08-23-sprint-3.2-academic-analytics-predictive-dashboard-design.md`](file:///home/p0xd/Documentos/NotiFast/docs/superpowers/specs/2026-08-23-sprint-3.2-academic-analytics-predictive-dashboard-design.md)

## Global Constraints
- Máximo ~200 líneas por archivo composable o ViewModel.
- Cero strings hardcodeados en UI (usar `res/values/strings.xml`).
- Cero colores arbitrarios quemados (usar `MaterialTheme.colorScheme` y parseo seguro en `ThemeUtils`).
- Tipografía monoespaciada académica (`Typography.monoAcademic` o `JetBrainsMonoFamily`) para cifras y porcentajes.
- TDD estricto (Red ➔ Green ➔ Refactor) en cálculos de dominio y ViewModels.
