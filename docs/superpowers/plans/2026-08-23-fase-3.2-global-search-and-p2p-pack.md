# Fase 3.2: Búsqueda Global Multientidad y Pack Académico P2P — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implementar al 100% la Fase 3.2 (Sprints 3.3 y 3.4) de NotiFast v3.0, introduciendo el motor de búsqueda global multientidad en tiempo real con debounce y normalización diacrítica, y el sistema de intercambio de asignaturas P2P ("Pack Académico") con compresión .notifast (GZIP + Base64), códigos QR offline y Android Sharesheet.

**Architecture:** Clean Architecture + MVVM con MVI Contract unidireccional. Casos de uso puros en Kotlin (`SearchGlobalUseCase`, `ExportSubjectPackageUseCase`, `ImportSubjectPackageUseCase`), serialización compacta y utilidades QR en capa de datos, y componentes modulares Tactile Studio 3.0 (≤ 200 LOC) en Jetpack Compose.

**Tech Stack:** Kotlin 2.0.21, Jetpack Compose Material 3, Hilt 2.59, Coroutines Flow, ZXing Core 3.5.3, GZIP/Base64/JSON.

**Spec:** [`docs/superpowers/specs/2026-08-23-fase-3.2-global-search-and-p2p-pack-design.md`](file:///home/p0xd/Documentos/NotiFast/docs/superpowers/specs/2026-08-23-fase-3.2-global-search-and-p2p-pack-design.md)

## Global Constraints
- Máximo ~200 líneas por archivo composable (modularizar en `components/`).
- Cero strings hardcodeados en UI (100% en `res/values/strings.xml` en español).
- Cero colores hexadecimales quemados (usar `MaterialTheme.colorScheme` y `ThemeUtils`).
- MVI estricto: un solo `StateFlow<UiState>` por ViewModel y eventos vía `onEvent()`.
- TDD estricto para toda la lógica de dominio y serialización.
