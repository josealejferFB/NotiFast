# Design Spec — Notes Hub 3.0: Digital Studio Notebook & Academic Dashboard

## 1. Visión y Objetivos del Rediseño

Transformar la pantalla principal de Apuntes (`NotesScreen.kt`) en el **Hub y Dashboard Académico Inteligente** central de NotiFast 3.0, alineado con el arquetipo *Tactile Papercraft / Studio Notebook* (`DESIGN.md`) y la Estrella Polar de serenidad y enfoque (`PRODUCT.md`).

### Objetivos Clave
1. **Claridad Inmediata (< 3 segundos):** Visualizar de un vistazo la actividad más próxima (próxima clase del día o evaluación más inminente) y las métricas académicas globales (promedio, notas, materias).
2. **Ergonomía de Estudio Táctil:** Tabs de estudio dual (Pestaña 1: Apuntes & Hero; Pestaña 2: Bento Grid de Materias), tarjetas tipo ficha bibliográfica con física de resortes `0.97f` y micro-bordes de 1dp.
3. **Búsqueda & Filtrado Contextual Dinámico:** Búsqueda en vivo combinada con chips de etiquetas temáticas (`#resumen`, `#examen`, etc.) y acceso directo a exportación en formato Markdown.
4. **Higiene de Código & Clean Architecture:** Todos los composables $\le 200$ LOC, un único `StateFlow<NotesUiState>`, cero strings quemados y cero colores mágicos en la UI.

## 3. Especificación Detallada de Componentes

### 3.1 `NotesDashboardHero.kt`
- **Widget de Próxima Actividad:**
  - Si hay clase hoy después de la hora actual: muestra icono de clase, nombre de la materia con color accesible, horario `08:00 - 10:00` en `JetBrains Mono`, aula/modalidad y botón directo de "Apuntar".
  - Si no hay más clases hoy pero hay evaluación pendiente: muestra icono de examen/tarea, fecha formateada, ponderación `%` y botón de "Estudiar".
  - Si no hay pendientes: banner sereno de "Todo al día".
- **Métricas Rápidas:**
  - 3 micro-cápsulas pergamino:
    1. **Apuntes:** Total de notas creadas.
    2. **Materias:** Cantidad de materias cursadas.
    3. **Promedio:** Promedio ponderado acumulado en `JetBrains Mono` con indicador de color (Verde/Ámbar/Índigo).

### 3.2 `NotesFilterBar.kt`
- Campo de búsqueda con fondo `surfaceContainer`, micro-borde animado al foco y botón de limpiar.
- Fila horizontal con selector de orden (`Recientes`, `Más Antiguas`, `Por Materia`) y chips redondeados de tags disponibles `#resumen`, `#examen`, etc., con animación táctil al seleccionar.

### 3.3 `NoteEstheticCard.kt`
- Tarjeta táctil con lomo vertical accesible (`ThemeUtils.getAccessibleColor()`).
- Título con `Plus Jakarta Sans` en negrita, preview de contenido de 2 líneas.
- Chips de etiquetas temáticas con fondo tonal.
- Indicador visual cuando contiene imagen adjunta.
- Botón rápido de exportación a Markdown (copia al portapapeles y comparte) con respuesta háptica.
- Física de resortes `0.97f` al interactuar.

### 3.4 `SubjectGridBento.kt`
- Cuadrícula de 2 columnas con tarjetas Bento de materias.
- Monograma o icono con color dinámico calibrado.
- Cifras académicas en `JetBrains Mono`: promedio actual, conteo de notas, evaluaciones completadas/pendientes.
- Acciones rápidas al pulsar o mantener pulsado.

## 4. Estado y Flujo de Datos (`NotesContract.kt` & `NotesViewModel.kt`)

### `NextActivity`
```kotlin
sealed interface NextActivity {
    data class ClassActivity(
        val subjectName: String,
        val startTime: String,
        val endTime: String,
        val classroom: String,
        val modality: String,
        val colorHex: String
    ) : NextActivity

    data class EvaluationActivity(
        val evaluation: Evaluation,
        val subjectColorHex: String
    ) : NextActivity

    data object FreeDay : NextActivity
}
```

### `NotesUiState`
```kotlin
data class NotesUiState(
    val isLoading: Boolean = false,
    val error: String? = null,
    val notes: Map<String, List<Note>> = emptyMap(),
    val rawNotes: List<Note> = emptyList(),
    val subjects: List<String> = emptyList(),
    val subjectInfos: List<SubjectInfo> = emptyList(),
    val nextActivity: NextActivity = NextActivity.FreeDay,
    val globalAverage: Double? = null,
    val totalNotesCount: Int = 0,
    val totalSubjectsCount: Int = 0,
    val currentFilter: NoteFilter = NoteFilter.RECIENTES,
    val searchQuery: String = "",
    val availableTags: List<String> = emptyList(),
    val selectedTag: String? = null,
    val expandedSubject: String? = null,
    val syncMessage: String? = null,
    val userFirstName: String = "",
    val userLastName: String = "",
    val userEmail: String = "",
    val userProfilePictureUrl: String? = null
)
```

### `NotesViewModel`
- Inyecta `NoteRepository`, `AuthRepository`, `EvaluationRepository`, `ScheduleRepository`, `CalculateWeightedAverageUseCase`.
- Realiza `combine` reactivo de notas, materias, horarios, evaluaciones y filtros.
- Calcula el día actual (`Calendar.getInstance().get(Calendar.DAY_OF_WEEK)`) y determina la próxima clase del día u horario más inminente, o en su defecto la evaluación más cercana.
- Calcula el promedio general ponderado de todas las materias.
