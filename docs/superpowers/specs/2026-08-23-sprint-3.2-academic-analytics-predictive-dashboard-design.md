## 🎯 1. Contexto y Objetivos

En NotiFast 3.0, el estudiante cuenta con un cálculo básico de promedio ponderado global y un simulador en la pantalla de detalle de materia. Sin embargo, para reducir la ansiedad académica y ofrecer valor predictivo real, el **Sprint 3.2** introduce un **Dashboard Predictivo y Diagnóstico Académico Integral** integrado dentro de la pestaña `Calificaciones` sin alterar la barra de navegación de 4 pestañas (`Apuntes`, `Agenda`, `Calificaciones`, `Ajustes`).

### Objetivos Clave:
1. **Cálculo de Diagnóstico y Salud Académica Multiescala:** Detección temprana de asignaturas en riesgo, cálculo de notas mínimas requeridas sobre el peso restante y tasa proyectada de éxito.
2. **Gráficos Nativos en Canvas Jetpack Compose:** Visualizaciones estadísticas fluidas, táctiles y reactivas (`AcademicProgressChart` y `GradeDistributionHistogram`) con tipografía `JetBrains Mono` y paleta HSL accesible.
3. **Correlación de Carga Horaria y Desempeño:** Cruce analítico entre la carga de horas de clase semanales (`Schedule`) y los promedios obtenidos por materia.
4. **Ergonomía UI Tactile Studio:** Conmutador segmentado táctil en `GradesScreen` (`[ Resumen Materias | Analíticas & Proyecciones ]`) manteniendo el límite estricto de $\le 200$ LOC por composable.

package com.notifast.app.domain.model

enum class SubjectHealthStatus {
    APPROVED,     // Ya alcanzó la nota mínima aprobatoria con las evaluaciones rendidas o 100% completado
    ON_TRACK,     // Promedio actual >= minPassingGrade y factible de aprobar
    AT_RISK,      // Promedio actual < minPassingGrade pero aún matemáticamente recuperable
    CRITICAL_FAIL // Matemáticamente imposible alcanzar minPassingGrade con el peso restante
}

data class SubjectAcademicHealth(
    val subjectName: String,
    val colorHex: String?,
    val currentAverage: Double,
    val evaluatedWeight: Double,      // 0..100%
    val remainingWeight: Double,      // 0..100%
    val accumulatedPoints: Double,    // Puntos obtenidos (ej. 14 * 0.3 = 4.2)
    val minGradeNeededToPass: Double, // Nota promedio necesaria en lo que queda para aprobar
    val status: SubjectHealthStatus,
    val weeklyHours: Double           // Horas de clase a la semana
)

data class GradeBandDistribution(
    val excellentCount: Int,  // Sobresaliente (>= 90% escala)
    val goodCount: Int,       // Notable / Bueno (>= 70% escala)
    val regularCount: Int,    // Regular / Aprobado (>= minPassingGrade)
    val atRiskCount: Int,     // En Riesgo / Desaprobado (< minPassingGrade)
    val totalEvaluated: Int
)

data class AcademicStats(
    val globalAverage: Double,
    val projectedPassingRate: Double, // % de materias en ON_TRACK o APPROVED
    val approvedSubjectsCount: Int,
    val totalSubjectsCount: Int,
    val subjectHealthList: List<SubjectAcademicHealth>,
    val atRiskSubjects: List<SubjectAcademicHealth>,
    val bestSubject: SubjectAcademicHealth?,
    val lowestSubject: SubjectAcademicHealth?,
    val gradeDistribution: GradeBandDistribution,
    val totalWeeklyClassHours: Double,
    val studyRecommendations: List<String>
)

## 🧮 3. Algoritmo y Caso de Uso `CalculateAcademicStatsUseCase`

El caso de uso es **100% agnóstico de UI**, determinista y con soporte multi-escala (`0-10`, `0-20`, `0-100`):

1. **Cálculo por Asignatura:**
   - Evaluaciones calificadas: $E_{eval} = \{ e \in \text{evals} \mid e.grade \neq null \lor e.isPresented \}$.
   - Suma de ponderaciones evaluadas: $W_{eval} = \sum w_i$ (normalizado a escala 100).
   - Puntos acumulados: $P_{acc} = \sum (g_i \cdot \frac{w_i}{100})$.
   - Peso restante: $W_{rem} = \max(0.0, 100.0 - W_{eval})$.
   - Nota mínima necesaria para aprobar ($N_{req}$):
     $$\text{Puntos Faltantes} = \max(0.0, \text{minPassingGrade} - P_{acc})$$
     $$N_{req} = \begin{cases} 0.0 & \text{si } P_{acc} \ge \text{minPassingGrade} \\ \frac{\text{Puntos Faltantes}}{W_{rem} / 100} & \text{si } W_{rem} > 0 \\ \infty & \text{si } W_{rem} = 0 \text{ y } P_{acc} < \text{minPassingGrade} \end{cases}$$
   - **Clasificación de Estado:**
     * `APPROVED`: si $P_{acc} \ge \text{minPassingGrade}$ o ($W_{rem} == 0$ y promedio $\ge \text{minPassingGrade}$).
     * `CRITICAL_FAIL`: si $N_{req} > \text{scale.maxGrade}$ (matemáticamente irrecuperable).
     * `AT_RISK`: si promedio actual $< \text{minPassingGrade}$ y $N_{req} \le \text{scale.maxGrade}$.
     * `ON_TRACK`: si promedio actual $\ge \text{minPassingGrade}$.

2. **Cálculo de Carga Horaria:**
   - Horas semanales a partir de `Schedule.startTime` y `Schedule.endTime` ("HH:mm").

3. **Generación de Recomendaciones Tácticas:**
   - Detección automática de materias críticas con metas concretas: *"Necesitas al menos 13.5 en el 40% restante de Cálculo I para asegurar aprobación"*.

## 🎨 4. Diseño Visual & Gráficos en Canvas Nativo (Tactile Studio 3.0)

### 4.1 `AcademicProgressChart.kt` (Canvas Jetpack Compose)
- **Renderizado Gráfico Directo:**
  - Eje horizontal/vertical con líneas guía sutiles en `outlineVariant` ($0.5\text{dp}$).
  - Barras redondeadas con el color HSL calibrado de cada asignatura.
  - Línea de corte de aprobación punteada en color ámbar/rojo con etiqueta `"Mínimo: X.X"` en `JetBrains Mono`.
  - Animación elástica de crecimiento (`Animatable(0f)` $\to$ `targetValue`) al entrar la pantalla.

### 4.2 `GradeDistributionHistogram.kt`
- 4 columnas o barras horizontales proporcionales:
  * 🟢 **Sobresaliente** ($[18..20]$ / $[9..10]$ / $[90..100]$)
  * 🔵 **Notable** ($[14..17.9]$ / $[7..8.9]$ / $[70..89]$)
  * 🟡 **Aprobado Regular** ($[11..13.9]$ / $[5..6.9]$ / $[50..69]$)
  * 🔴 **En Riesgo** ($< 11$ / $< 5$ / $< 50$)
- Porcentajes calculados y renderizados en `Typography.monoAcademic`.

### 4.3 `AcademicAnalyticsContent.kt` & Bento Grid
- **Hero Diagnostic Bento:**
  - Píldora de Tasa Proyectada (ej. `85% Aprobación Proyectada`).
  - Monogramas de Materia con Mayor Rendimiento vs Materia de Mayor Esfuerzo.
- **Early Warning Card:**
  - Si hay materias en `AT_RISK` o `CRITICAL_FAIL`, destaca la tarjeta con acento Terracotta/Crimson, indicando exactamente los puntos faltantes y la nota mínima requerida.
