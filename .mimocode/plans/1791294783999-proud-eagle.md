# NotiFast — Sanitización de Lógica de Negocio (Plan de Implementación)

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Eliminar redundancias, bugs y estados bloqueantes de toda la lógica de negocio (apuntes, materias, evaluaciones, horarios, calificaciones, búsqueda, alertas, pack P2P), unificando fórmulas, reestructurando modelos (`subjectId`, ciclo académico, escala por evaluación) y purgando código muerto.

**Architecture:** Clean Architecture estricta sobre `com.notifast.app` (package real — AGENTS.md dice `com.example.notifast` y está desactualizado). Offline-first Room (los repos Firestore se eliminan). Una única política de notas/pesos en `domain/`, consumida por todos los ViewModels.

**Tech Stack:** Kotlin 2.0.21, Jetpack Compose + M3, Hilt 2.59, Room, WorkManager 2.10.0, JUnit4 + MockK + Turbine.

**Spec:** Decisiones validadas con el usuario en esta sesión (ver §Decisiones de negocio bloqueadas).

## Decisiones de negocio bloqueadas

| # | Decisión |
|---|---|
| D1 | **Fórmula de promedio unificada:** pesos como % de 100. Si Σpesos > 100 → renormalizar proporcionalmente. Si ninguna eval tiene peso → reparto equitativo 100/n. Peso null/0 **no aporta** (no se inventa 1.0). |
| D2 | **Conteo:** una evaluación cuenta en el promedio **solo si `isPresented == true` Y `grade != null`**. Presentada sin nota: **no cuenta** hasta que se cargue la nota (se muestra como "rendida, sin calificar"). |
| D3 | **Pesos:** siempre % de 100. Validar en create/edit que la suma por materia ≤ 100%. `availableWeight` se pasa de verdad al slider. |
| D4 | **Umbrales:** `GradeScale.minPassingGrade` como default; si el usuario editó `minPassingGrade` en Settings, ese valor manda. Eliminar `GradeConstants.PASSING_THRESHOLD/MAX_GRADE` de la UI y el umbral 3.0 del hero. |
| D5 | **Escala por evaluación:** se fija al calificar (`Evaluation.gradeScaleId`). Cambiar el default en Settings **no** reinterpreta notas guardadas. Migración: marcar existentes con el default actual. |
| D6 | **`remainingWeight`** = suma de pesos de evaluaciones **pendientes** (`!isPresented \|\| grade == null`). Si no hay pendientes → 0 y el status lo decide el acumulado. Nada de `100 − evaluated` fantasma. |
| D7 | **`subjectId` estable (UUID)** en `SubjectData`/`SubjectEntity`; `Note`/`Evaluation`/`Schedule` cuelgan de `subjectId`. Nombre es solo display. Renombrar materia deja de romper joins. |
| D8 | **Ciclo académico en la materia** (`SubjectData.cycle`, ej. `2026-I`). `UserPrefs.activeAcademicCycle` filtra materias y todo lo que cuelga de ellas (promedios, stats, agenda de evaluaciones). Migración: materias existentes → ciclo default de Settings. |
| D9 | **Alertas:** dejan de sonar al tener `grade != null` **O** `isPresented == true`. |
| D10 | **Clases virtuales = clases con día/hora** (bug). Permitir slot horario y alertas; solo cambia `meetingUrl`. |
| D11 | **Import/Export P2P se arregla entero:** OVERWRITE real, fechas UTC de verdad, validación de grade/weight/day/times, Result transaccional. |
| D12 | **Purgar:** repos Firestore, `DeleteSubjectCascadeUseCase`, `GetSubjectDetailUseCase`, `GetNotesWithSubjectInfoUseCase`, `FirebaseAuthDataSource`, feature muerta de filtros de apuntes, ~8 componentes muertos de notes, átomos sin uso, settings muertos (`firstDayOfWeek`, `ExportData` stub se implementa o se quita). |
| D13 | **Alcance:** bugs + dead code + unificar lógica + limpieza UI redundante + reestructurar modelos. **No** rediseñar pantallas ni añadir features nuevas. |

## Task 1: `GradePolicy` — fuente única de verdad de notas/pesos

**Files:**
- Create: `app/src/main/java/com/notifast/app/domain/model/GradePolicy.kt`
- Create: `app/src/test/java/com/notifast/app/domain/model/GradePolicyTest.kt`
- Modify: `app/src/main/java/com/notifast/app/domain/model/GradeScale.kt` (helpers `min/max/passingFor(custom)`)

**Interfaces (produces):**
```kotlin
object GradePolicy {
    fun countsForAverage(e: Evaluation): Boolean          // isPresented && grade != null
    fun isPending(e: Evaluation): Boolean                // !isPresented || grade == null
    fun effectiveWeights(evals: List<Evaluation>): Map<String, Double> // id -> peso % normalizado
    fun weightedAverage(evals: List<Evaluation>): Double? // null si ninguna cuenta
    fun accumulatedPoints(evals: List<Evaluation>): Double
    fun evaluatedWeight(evals: List<Evaluation>): Double
    fun remainingWeight(evals: List<Evaluation>): Double  // Σ pesos de pendientes (D6)
    fun resolveMinPassing(scale: GradeScale, custom: Double?): Double
    fun validateGrade(grade: Double, scale: GradeScale): Boolean
    fun clampGrade(grade: Double, scale: GradeScale): Double
}
```

**Rules encoded (D1-D3, D6):**
- `countsForAverage` = `isPresented && grade != null`.
- Pesos: si **alguna** eval tiene `weight > 0`, las que tienen peso usan `weight` (en %) y las null/0 **no aportan**. Si **ninguna** tiene peso, reparto `100.0 / n` a todas las que cuentan (y a las pendientes para `remainingWeight`).
- Si Σpesos explícitos > 100, renormalizar: `w' = w / Σw * 100`.
- `weightedAverage = Σ(grade * w/100) / (evaluatedWeight/100)` sobre las que cuentan. `null` si `evaluatedWeight == 0`.
- `remainingWeight` = Σ pesos normalizados de `isPending`.
- `accumulatedPoints = Σ(grade * w/100)` sobre las que cuentan.
