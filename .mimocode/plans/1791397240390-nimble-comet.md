# Editor Premium de Apuntes (OneNote-like) — Plan de Implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Transformar el editor de apuntes de un editor markdown tipo IDE a una experiencia de cuaderno premium inspirada en OneNote: bloques reordenable, texto rico sin sintaxis visible, multi-foto inline, anotación/dibujo sobre fotos, checklists interactivos y fórmulas con render nativo.

**Architecture:** Motor de bloques serializados como JSON en Room (migración 2→3), feature unificada `noteeditor` con MVI, canvas de dibujo con `pointerInput`/`Path` vectorial, cámara vía `TakePicture`+FileProvider, render matemático nativo Compose. Offline-first, sin dependencias pesadas nuevas.

**Tech Stack:** Kotlin 2.0.21, Jetpack Compose (BOM 2024.09.00), Room 2.7.2, Hilt 2.59, Coil 2.7.0, Gson (ya presente para P2P), ActivityResultContracts.TakePicture. Sin CameraX, sin WebView, sin librerías de rich-text externas.

**Spec:** Decisiones cerradas con el usuario (brainstorming, esta sesión). Ver sección "Decisiones de diseño".

---

## Global Constraints (de AGENTS.md + Design 3.0)

- **Limpieza:** KISS, YAGNI, Clean Architecture estricta. Máx **~250 LOC por archivo composable**.
- **MVI:** Un solo `data class` UiState + `sealed interface` Event + un solo `StateFlow` + `onEvent()`. Cero StateFlows paralelos.
- **Colores:** Siempre `MaterialTheme.colorScheme.*` + `ThemeUtils` / aliases `Ruby`/`Aqua`. Cero `Color(0xFF...)` hardcodeados.
- **Strings:** Todo texto visible en `res/values/strings.xml` (español), consumido con `stringResource()`. Código en inglés.
- **Lógica:** Cero lógica de negocio en `@Composable`. Cálculos en ViewModel / Use Cases / `domain/util/`.
- **Errores:** `Result<T>` en repositorios. Cero `catch {}` vacíos. Log + `uiState.error` → feedback visual.
- **Ciclo de vida:** `collectAsStateWithLifecycle()`, `LaunchedEffect` para side-effects. Navegación jamás durante composición.
- **Átomos:** Reutilizar `presentation/atoms/` (NotiFastButton, Card, Dialog, TopBar, EmptyState, ImagePickerField, StudyBackground...). Nuevos átomos van en `atoms/`.
- **Tests:** TDD para toda lógica nueva (bloques, serialización, strokes, math, VMs). Suite actual: 260 tests — no regresionar.
- **Build gate:** `./gradlew assembleDebug` + `./gradlew test` en verde antes de cada commit de fase.

## Modelo de datos propuesto

### Bloques serializados como JSON (columna Room)

**Por qué JSON y no tabla `NoteBlock`:** el contenido de una nota se lee/escribe como unidad (auto-save, P2P export, undo). JSON en una columna evita N queries, JOINs y problemas de orden. La búsqueda extrae texto plano al vuelo. Escala perfecto para el tamaño real de una nota de estudiante.

```kotlin
// data/model/NoteBlock.kt — modelo de dominio (sealed)
sealed class NoteBlock {
    abstract val id: String

    data class Heading(
        override val id: String,
        val text: String,
        val level: Int,               // 1..3
        val spans: List<TextSpan> = emptyList()
    ) : NoteBlock()

    data class Paragraph(
        override val id: String,
        val text: String,
        val spans: List<TextSpan> = emptyList()
    ) : NoteBlock()

    data class BulletList(
        override val id: String,
        val items: List<ListItem> = emptyList()
    ) : NoteBlock()

    data class Checklist(
        override val id: String,
        val items: List<CheckItem> = emptyList()
    ) : NoteBlock()

    data class Quote(
        override val id: String,
        val text: String,
        val spans: List<TextSpan> = emptyList()
    ) : NoteBlock()

    data class Image(
        override val id: String,
        val path: String,             // file://... en filesDir
        val caption: String = "",
        val widthRatio: Float = 1f    // ancho relativo al contenedor
    ) : NoteBlock()

    data class MathBlock(
        override val id: String,
        val source: String,           // notación interna (ver MathRenderer)
        val display: Boolean = true   // display vs inline
    ) : NoteBlock()

    data class Divider(
        override val id: String
    ) : NoteBlock()
}

data class TextSpan(
    val start: Int,
    val end: Int,
    val styles: Set<TextStyle>       // BOLD, ITALIC, UNDERLINE, STRIKETHROUGH, HIGHLIGHT
)

data class ListItem(val text: String, val spans: List<TextSpan> = emptyList())
data class CheckItem(
    val text: String,
    val isChecked: Boolean = false,
    val spans: List<TextSpan> = emptyList()
)

enum class TextStyle { BOLD, ITALIC, UNDERLINE, STRIKETHROUGH, HIGHLIGHT }
```

### Anotación sobre fotos (capa vectorial)

```kotlin
// data/model/PhotoAnnotation.kt
data class PhotoAnnotation(

data class Stroke(
    val points: List<Offset>,         // serializado como List<Pair<Float,Float>>

    val tool: DrawTool,               // PEN, HIGHLIGHTER, ERASER

)

data class AnnotationText(
    val x: Float, val y: Float,
    val text: String,
    val color: Int,
    val sizeSp: Float
)

data class Arrow(
    val startX: Float, val startY: Float,
    val endX: Float, val endY: Float,
    val color: Int,
    val width: Float
```

**Serialización de anotaciones:** JSON en tabla `photo_annotations` o embebido en el bloque Image (columna `annotationJson`). Se recomienda **embebido en el bloque Image** para mantener la nota como unidad. Al exportar/flatten se rasteriza a un JPEG final (la capa vectorial se conserva para re-editar).


3. Mantener `content` y `imageUrl` por compatibilidad durante la migración; el repo puede leer ambos (legacy → parse on read) hasta que todos los datos migren.

### MVI Contract (resumen)

```kotlin
data class NoteEditorUiState(
    val noteId: String? = null,          // null = crear
    val subject: String = "",
    val subjects: List<SubjectData> = emptyList(),
    val title: String = "",
    val blocks: List<NoteBlock> = emptyList(),
    val tags: List<String> = emptyList(),
    val focusedBlockId: String? = null,
    val isEditMode: Boolean = true,
    val isLoading: Boolean = false,
    val isSaved: Boolean = false,
    val syncStatus: String? = null,      // "Guardando...", "Guardado"
    val error: String? = null
)

sealed interface NoteEditorEvent {
    // Metadata
    data class TitleChanged(val title: String) : NoteEditorEvent
    data class SubjectChanged(val subject: String) : NoteEditorEvent
    data class TagToggled(val tag: String) : NoteEditorEvent
    data class CustomTagAdded(val tag: String) : NoteEditorEvent
    data class CustomTagRemoved(val tag: String) : NoteEditorEvent

    // Bloques
    data class BlockTextChanged(val blockId: String, val text: String) : NoteEditorEvent
    data class BlockSpansChanged(val blockId: String, val spans: List<TextSpan>) : NoteEditorEvent
    data class BlockFocused(val blockId: String?) : NoteEditorEvent
    data class BlockMoved(val fromIndex: Int, val toIndex: Int) : NoteEditorEvent
    data class BlockDeleted(val blockId: String) : NoteEditorEvent
    data class BlockInserted(val afterBlockId: String?, val type: BlockType) : NoteEditorEvent
    data class BlockTypeChanged(val blockId: String, val newType: BlockType) : NoteEditorEvent

    // Checklist
    data class CheckItemToggled(val blockId: String, val itemIndex: Int) : NoteEditorEvent
    data class CheckItemTextChanged(val blockId: String, val itemIndex: Int, val text: String) : NoteEditorEvent
    data class CheckItemAdded(val blockId: String) : NoteEditorEvent
    data class CheckItemRemoved(val blockId: String, val itemIndex: Int) : NoteEditorEvent

    // Imágenes
    data class ImageBlockAdded(val afterBlockId: String?, val uri: Uri) : NoteEditorEvent
    data class ImageBlockRemoved(val blockId: String) : NoteEditorEvent
    data class ImageAnnotationSaved(val blockId: String, val annotation: PhotoAnnotation) : NoteEditorEvent

    // Math
    data class MathSourceChanged(val blockId: String, val source: String) : NoteEditorEvent

    // Persistencia
    data object SaveClicked : NoteEditorEvent
    data object ClearError : NoteEditorEvent
    data object ResetState : NoteEditorEvent
}

enum class BlockType { HEADING, PARAGRAPH, BULLET_LIST, CHECKLIST, QUOTE, IMAGE, MATH, DIVIDER }
```

## Riesgos técnicos y mitigaciones

| Riesgo | Mitigación |
|---|---|
| Rendimiento con muchas imágenes/strokes | LazyColumn para bloques; strokes vectoriales (no bitmaps por trazo); flatten solo al export; Coil con size constraints |
| Undo/redo de bloques y trazos | Stack simple en VM (bloques) y en `DrawingCanvasState` (trazos). No undo global histórico complejo (YAGNI) |
| Compose Canvas performance al dibujar | Dibujar solo el Path en progreso + snapshot de strokes previos; evitar recomposición por punto |
| Migración corrupta de markdown | Parser tolerante a errores (lo que no entienda → Paragraph). Tests con fixtures reales de `MarkdownParserTest` |
| Tests rotos al cambiar modelo | Actualizar en la misma task del cambio (TDD). `TestDataFactory.createNote` actualizado primero |
| Tamaño de archivos (fotos + anotaciones) | JPEG 80% ya existente; anotaciones vectoriales (JSON pequeño); flatten solo para export/PDF |
| 250 LOC por archivo | Components ya desglosados en el design; cada composable tiene una responsabilidad |
